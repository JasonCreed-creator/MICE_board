- 대상 독자: 개발자가 아닌 기획자·팀원
- 기준: 2026-09-14 · 구글 스프레드시트 + Apps Script 웹 앱(결정 D1) · 대시보드에서 추가·수정·삭제(4턴, 결정 D6~D10) · 마일스톤 아래 **업무 블럭 · 주석 · 계획 공수 자동 합산**(5턴, 결정 D11~D16 — §6.11~§6.13)
- 읽는 법: 모든 단계는 **어느 화면 → 어느 메뉴 → 무엇을 클릭 → 무엇이 보여야 정상** 순서로 적었습니다. "정상" 표시가 안 나오면 §7 문제 해결 표로 가세요.

## 1. 새 스프레드시트 만들기

1. 브라우저에서 **구글 드라이브**(drive.google.com) 를 엽니다. 회사 계정으로 로그인돼 있는지 오른쪽 위 프로필 사진으로 확인합니다.
2. 왼쪽 위 **+ 신규** → **Google 스프레드시트** → **빈 스프레드시트** 를 클릭합니다.
3. 왼쪽 위 "제목 없는 스프레드시트" 를 클릭 → **마이스 비즈 팀 보드** 로 바꾸고 `Enter`.
4. 시트 시간대를 서울로 맞춥니다: 메뉴 **파일** → **설정** → **일반** 탭 → **시간대** 를 **(GMT+09:00) 서울** 로 → **설정 저장**. (로캘도 "대한민국" 이면 좋습니다.)
5. 정상: 탭이 "시트1" 하나뿐인 빈 시트가 열려 있습니다. 이 시트는 이대로 두세요. 다음 장에서 스크립트가 탭 11개를 만듭니다.

## 2. Apps Script 에 파일 3개 넣기

### 2.1 편집기 열기

1. 시트 메뉴 **확장 프로그램** → **Apps Script** 를 클릭합니다. 새 탭에서 편집기가 열립니다.
2. 정상: 왼쪽 "파일" 목록에 `Code.gs` 하나가 있고, 가운데에 `function myFunction() {}` 몇 줄이 보입니다.
3. 왼쪽 위 "제목 없는 프로젝트" 를 클릭 → **마이스 비즈 팀 보드** 로 바꾸고 **이름 바꾸기**. (권한 창에 이 이름이 표시됩니다.)

### 2.2 `Code.gs` 교체

1. 가운데 편집 영역을 클릭 → `Ctrl+A` → `Delete` 로 기존 내용을 모두 지웁니다.
2. 이 폴더의 `apps-script/Code.gs` 를 메모장으로 열어 `Ctrl+A` → `Ctrl+C`.
3. 편집기로 돌아와 `Ctrl+V`.
4. 정상: 첫 줄 근처에 `TZ`, `SHEETS` 같은 상수 정의가 보이고, 아래로 길게 내려가면 `function doGet`, `function getBootstrap` 이 있습니다.

### 2.3 `index` HTML 파일 추가

1. 왼쪽 "파일" 글자 옆 **+** 를 클릭 → **HTML** 을 선택합니다.
2. 파일 이름 입력칸에 **index** 라고만 입력하고 `Enter`. (확장자 `.html` 은 자동으로 붙습니다. 이름이 `index` 가 아니면 웹 앱이 열리지 않습니다.)
3. 새 파일 안의 기본 내용을 `Ctrl+A` → `Delete` 로 지웁니다.
4. 이 폴더의 `apps-script/index.html` 을 메모장으로 열어 `Ctrl+A` → `Ctrl+C` → 편집기에 `Ctrl+V`.
5. 정상: 왼쪽 파일 목록에 `Code.gs` 와 `index.html` 두 개가 보입니다.

> `preview/dashboard-preview.html` 을 붙이면 안 됩니다. 그 파일은 가상 데이터가 들어 있는 미리보기 전용입니다. 반드시 `apps-script/index.html` 을 사용하세요.

### 2.4 `appsscript.json` 교체

1. 왼쪽 세로 아이콘 중 **프로젝트 설정**(톱니 모양) 을 클릭합니다.
2. **"appsscript.json" 매니페스트 파일을 편집기에 표시** 체크박스를 켭니다.
3. 왼쪽 세로 아이콘 **편집기**(`< >` 모양) 로 돌아옵니다. 파일 목록에 `appsscript.json` 이 추가돼 있습니다. 클릭합니다.
4. 내용을 `Ctrl+A` → `Delete` 로 지우고, 이 폴더의 `apps-script/appsscript.json` 내용을 붙입니다.
5. 정상: `"timeZone": "Asia/Seoul"`, `"executeAs": "USER_ACCESSING"`, `"access": "DOMAIN"` 세 줄이 보입니다.

### 2.5 저장

1. 위쪽 **프로젝트 저장**(디스크 아이콘) 을 클릭하거나 `Ctrl+S`.
2. 정상: 파일 이름 옆의 주황색 점(저장 안 됨 표시)이 세 파일 모두 사라집니다. 아래쪽에 빨간 오류 줄이 뜨지 않습니다.

## 3. 초기 설정 실행 — 탭 11개 만들기

### 3.1 `setupSheets` 실행과 권한 허용

1. 편집기 왼쪽 파일 목록에서 `Code.gs` 를 클릭합니다.
2. 위쪽 도구 막대의 **함수 선택 드롭다운**("디버그" 오른쪽) 을 열어 **setupSheets** 를 선택합니다.
   - 빈 시트로 시작하려면 **setupSheetsEmpty** 를 선택합니다. 처음에는 샘플이 있는 `setupSheets` 를 권장합니다. 화면을 확인한 뒤 §3.3 에서 샘플을 지우면 됩니다.
3. **실행** 을 클릭합니다.
4. **승인 필요** 창이 뜹니다 → **권한 검토** 클릭.
5. 계정 선택 창 → 시트를 만든 **회사 계정** 을 클릭.
6. "Google에서 확인하지 않은 앱" 화면이 나오면 → 왼쪽 아래 **고급** 클릭 → 맨 아래 **마이스 비즈 팀 보드(안전하지 않음)으로 이동** 클릭. (회사 내부 스크립트라 구글의 별도 심사를 받지 않아 뜨는 안내입니다. 정상입니다.)
7. 권한 목록(스프레드시트 보기·수정 · 안내 메시지 표시) → **허용**.
8. 정상: 편집기 아래 **실행 로그** 에 "실행이 시작됨" → 몇 초 뒤 "실행이 완료됨" 이 찍힙니다. 스프레드시트 탭으로 돌아가면 오른쪽 아래에 **"팀 보드 초기 설정 — 탭 11개 생성 · 0개 건너뜀"** 알림이 잠깐 보일 수 있습니다.

### 3.2 시트에서 확인

1. 스프레드시트 탭으로 돌아가 **새로고침(F5)** 합니다.
2. 정상 1: 아래쪽에 탭 11개 **프로젝트 · 배정 · 공수기록 · 팀원 · 마일스톤 · 정산 · 설정 · 변경이력 · 세부항목 · 주석 · 업무블럭** 이 있습니다. (`변경이력` 은 대시보드에서 무엇을 바꿨는지 자동으로 쌓이는 탭입니다 — §6.9. `세부항목`·`주석` 은 마일스톤 아래 업무 블럭과 주석이 쌓이는 탭 — §6.11 · §6.12. `업무블럭` 은 파트별 업무 블럭 목록(카탈로그)으로 기본 33개가 채워져 있고 시트에서만 고칩니다. 예전에 만든 시트라 이 탭들이 없어도 됩니다 — `변경이력`·`세부항목`·`주석` 은 대시보드에서 처음 저장할 때 자동으로 생기고, **`업무블럭` 탭이 없어도 대시보드는 코드에 들어 있는 기본 카탈로그를 그대로 씁니다.** 카탈로그를 다듬고 싶을 때 메뉴 **팀 보드 → 드롭다운 목록 새로고침** 을 한 번 누르면 이 탭이 만들어지고, 그때부터 시트에서 고치면 됩니다.) 처음 있던 빈 "시트1" 은 자동으로 정리됩니다. (남아 있으면 우클릭 → 삭제해도 됩니다.)
3. 정상 2: `setupSheets` 로 실행했다면 `팀원` 탭에 팀원1~팀원5, `프로젝트` 탭에 가상 프로젝트 5건이 들어 있습니다.
4. 정상 3: 메뉴 막대에 **팀 보드** 메뉴가 생겼습니다. 열면 7개 항목이 보입니다.

| 메뉴 항목 | 하는 일 |
|---|---|
| 초기 설정 실행(샘플 포함) | 탭 11개 생성(`업무블럭` 탭에는 기본 카탈로그 33개) + 가상 팀원 5명·프로젝트 5건. 이미 있는 탭은 건너뜁니다 |
| 초기 설정 실행(빈 시트) | 탭 11개와 설정 값·기본 카탈로그만 생성 |
| 샘플 데이터 지우기(실제 입력 시작) | 프로젝트·배정·공수기록·팀원·마일스톤·정산 탭의 입력 내용을 한 번에 지움(헤더·드롭다운·수식·설정 탭·변경이력 탭·업무블럭 탭은 유지). 확인 창에서 **예** (§3.3) |
| 프로젝트 ID 채우기 | `프로젝트` 탭에서 ID 가 빈 행에 ID·등록일을 채움 (여러 행을 한꺼번에 붙여넣은 뒤 사용) |
| 선택 프로젝트 표준 마일스톤 생성 | `프로젝트` 탭에서 선택한 행의 프로젝트에 표준 마일스톤 9종을 만듦 (§6.2) |

| 대시보드 주소 보기 | 배포한 웹 앱 주소를 보여줌 (§4 이후) |

### 3.3 샘플을 지우고 실제 데이터로 시작하기

화면을 확인했으면 샘플을 실제 데이터로 바꿉니다. **가장 쉬운 방법**: 메뉴 **팀 보드 → 샘플 데이터 지우기(실제 입력 시작)** → 확인 창에서 **예**. 6개 탭의 입력 칸이 한 번에 비워지고 `설정` 탭·`변경이력` 탭·`업무블럭` 탭(카탈로그)·헤더·드롭다운·수식 열은 남습니다. 그 뒤 팀원(§6.8) → 프로젝트(§6.2) 순서로 실제 데이터를 넣으면 됩니다 — 대시보드에서 넣어도 되고 시트에 직접 넣어도 됩니다. 메뉴가 안 보이거나 손으로 지우려면 아래 절차를 따릅니다. **`설정` 탭은 건드리지 않습니다.**

1. `팀원` 탭: 2행부터 팀원1~팀원5 의 **이름 · 주역할 · 월 가용 M/D · 상태** 를 실제 팀원으로 덧씌워 입력합니다. 남는 샘플 행은 행 번호 우클릭 → **행 삭제**. 팀원이 더 많으면 아래에 이어서 입력합니다. 색상 열은 비워도 됩니다(화면이 자동 배색). 팀 밖에서 도와주는 영업·지원 인력도 배정하려면 팀원 탭에 넣되 **상태를 "지원"** 으로 두세요. 배정은 되지만 가동률 히트맵·미기록 경고에는 나오지 않습니다("지원"이 목록에 없으면 메뉴 **팀 보드 → 드롭다운 목록 새로고침**).
2. `프로젝트` · `배정` · `공수기록` 탭: 2행부터 마지막 데이터 행까지 행 번호를 드래그로 선택 → 우클릭 → **행 삭제**.
3. `마일스톤` · `정산` 탭: 행을 지우지 말고 **입력 칸만** 지웁니다. 수식 열이 있기 때문입니다.
   - `마일스톤`: 2행부터 A~E열(프로젝트ID~담당)만 드래그 선택 → `Delete`. F열(상태)은 그대로.
   - `정산`: 2행부터 A~C열, F~G열, J열만 선택 → `Delete`. D·E·H·I열(실마진·실마진율·쇼업률·게런티 달성률)은 그대로.
4. 정상: 대시보드를 새로고침하면 팀원 명단은 실제 이름, 프로젝트는 0건으로 보입니다. ("조건에 맞는 프로젝트가 없습니다" 안내가 뜨는 것이 정상입니다.)

> 팀원 이름은 다른 탭(`프로젝트` 담당PM · `배정` · `공수기록` · `마일스톤` 담당)이 그대로 참조합니다. 나중에 이름을 바꾸면 **편집 → 찾기 및 바꾸기(Ctrl+H)** 로 전체 탭에서 함께 바꾸세요.

## 4. 웹 앱 배포 — 대시보드 주소 만들기

### 4.1 배포

1. Apps Script 편집기 오른쪽 위 파란 **배포** 버튼 → **새 배포**.
2. 왼쪽 위 **유형 선택** 옆 톱니 아이콘 → **웹 앱** 을 체크합니다.
3. 오른쪽 구성 칸을 채웁니다.

| 항목 | 값 |
|---|---|
| 설명 | `1차 배포` (아무 메모나 가능) |
| 다음 사용자 인증 정보로 실행 | **웹 앱에 액세스하는 사용자** |
| 액세스 권한이 있는 사용자 | **[회사 이름] 내 모든 사용자** |

   - "웹 앱에 액세스하는 사용자" 로 두어야 배정 저장·완료 처리를 누른 사람이 시트의 수정 기록에 본인 이름으로 남습니다.
   - 액세스 목록에 "[회사 이름] 내 모든 사용자" 가 없으면 §7 표를 보세요.
4. **배포** 클릭 → 권한 창이 다시 뜨면 §3.1 의 4~7번과 같은 순서로 **허용**.
5. 정상: "배포가 업데이트되었습니다" 창에 **웹 앱 URL** 이 보입니다. **복사** 를 누르고 메모해 둡니다. **완료**.
6. 새 버전을 배포한 뒤(§8) 처음 열면 **권한 화면이 한 번 더 나올 수 있습니다** — 변경 이력에 "누가 바꿨는지"(사용자 이메일)를 기록하기 위한 권한입니다. §3.1 의 4~7번과 같은 순서로 **허용** 하면 됩니다. 팀원도 각자 한 번씩 거칩니다.

### 4.2 처음 열기

1. 새 탭에 복사한 주소를 붙여 엽니다.
2. 처음 한 번은 권한 창이 뜹니다. **권한 검토** → 계정 선택 → (필요하면 **고급** → **…(안전하지 않음)으로 이동**) → **허용**. 팀원마다 자기 계정으로 한 번씩 거칩니다.
3. 정상 — 다음이 보이면 성공입니다.

| 위치 | 보여야 하는 것 |
|---|---|
| 브라우저 탭 제목 | **마이스 비즈 팀 보드** |
| 화면 왼쪽 위 | 작은 글씨 "마이스 비즈 팀", 큰 글씨 "팀 프로젝트 보드" |
| 오른쪽 위 정보줄 | **기준일 (오늘 날짜) · 데이터 갱신 (지금 시각) · 시트 연결** |
| 오른쪽 위 버튼 | **시트 열기** (누르면 스프레드시트가 새 탭에 열림) |
| 탭 5개 | **A. 포트폴리오 / B. 배정 보드 / C. 공수 관리 / D. 투입 대비 성과 / E. 이번 주** |
| 탭 아래 | 핵심 지표 4칸(진행 중 프로젝트 · 이달 행사 · 팀 계획 가동률 · 지연 마일스톤) + 필터(유형 · 담당 책임자 · 상태 · 기간) |

> 정보줄에 "샘플 데이터" 라고 나오면 `index` 파일에 미리보기 파일을 잘못 붙인 것입니다. §2.3 을 다시 하고 §8 절차로 새 버전을 배포하세요.

## 5. 팀에 공유

### 5.1 시트 공유

1. 스프레드시트 오른쪽 위 **공유** → 팀원 이메일 입력 → 권한 **편집자** → **보내기**.
2. 팀원 전원을 **편집자** 로 둡니다. 대시보드는 팀원 각자의 권한으로 시트를 읽고 쓰기 때문에, 시트 권한이 없으면 대시보드도 열리지 않습니다.

### 5.2 대시보드 주소 공유

1. 웹 앱 주소는 §4.1 에서 복사한 것을 쓰거나, 시트 메뉴 **팀 보드 → 대시보드 주소 보기** 로 다시 볼 수 있습니다. 정상: "대시보드 주소" 창에 주소와 "이 주소를 복사해 팀에 공유하세요" 안내가 보입니다. "아직 웹 앱으로 배포되지 않았습니다" 가 나오면 §4 를 먼저 하세요.
2. 팀 채널에 주소를 공유하고 각자 **북마크** 하도록 안내합니다.
3. 처음 여는 팀원은 §4.2 의 권한 창을 한 번 거칩니다.

### 5.3 접근이 안 될 때

| 팀원이 보는 화면 | 조치 |
|---|---|
| "액세스 권한이 필요합니다" / 권한 요청 화면 | 시트 공유가 안 된 것. §5.1 로 편집자 추가 |
| "이 앱에 액세스할 수 없습니다" / 로그인 반복 | 회사 계정이 아닌 개인 계정으로 열었음. 시크릿 창에서 회사 계정으로만 로그인해 다시 열기 |
| 하얀 화면에 "화면을 불러오지 못했습니다" | §7 표 참고 |

## 6. 주간 운영 루틴

### 6.1 월요일 오전 — 지난주 공수 입력 (5분)

지난주에 어디에 얼마나 들어갔는지 적습니다. 한 사람이 2~4행이면 충분합니다.

**방법 1 (권장) — 대시보드 C. 공수 관리 → 공수 입력 카드**

1. 대시보드 **C. 공수 관리** 탭 → 아래쪽 **공수 입력** 카드.
2. **팀원** 에서 본인 → **주차** 에서 **지난주 월요일** 날짜를 고릅니다. (위 **주간 기록 현황** 표에서 본인 이름 × 주차 칸을 클릭해도 같은 카드가 그 팀원·주차로 열립니다.)
3. 이미 적은 행이 있으면 표에 나옵니다. **행 추가** 로 줄을 만들고 **프로젝트 코드**(프로젝트 ID, 또는 공통 코드 **G-내부**(회의·관리) / **G-영업**(미성사 제안) / **G-휴가**) · **실투입 M/D**(0.5 단위) · 메모(선택)를 적습니다. 잘못 만든 줄은 그 행의 **제거**.
4. **저장** 클릭.
5. 정상: 오른쪽 아래에 저장 완료 알림. 시트 `공수기록` 탭에 그 팀원·주차의 행이 들어가고 **기록일시** 가 자동으로 채워집니다. **E. 이번 주 → 주간 기록 미제출** 에서 본인 이름이 사라집니다.
   - 같은 프로젝트 코드를 두 줄에 적으면 `2번째 행: ○○ 이(가) 같은 주차에 두 번 있습니다. 한 행으로 합치세요.` 오류가 카드 안에 뜹니다 — 한 줄로 합치세요.
   - 한 주 합계가 **5.0 을 넘으면** `이번 주 합계 5.5 M/D 가 주 5.0 을 넘습니다. 맞는지 확인하세요.` 경고가 뜹니다. 실제로 맞으면 그대로 저장할 수 있고(경고는 막지 않습니다), 아니면 값을 고치세요.
   - 저장은 **그 팀원·그 주차의 행을 통째로 바꿉니다**. 다른 사람·다른 주차 행은 건드리지 않습니다. 지난 주차를 고칠 때도 같은 방법입니다.

**방법 2 — 시트 `공수기록` 탭에 직접 입력** (대시보드가 안 열릴 때)

| 열 | 입력 | 예 |
|---|---|---|
| 주차 | **지난주 월요일** 날짜 | `2026-09-07` |
| 팀원 | 드롭다운에서 본인 | `김OO` |
| 프로젝트ID | 드롭다운에서 프로젝트 ID, 또는 공통 코드 **G-내부**(회의·관리) / **G-영업**(미성사 제안) / **G-휴가** | `P-2026-003` |
| 실투입 M/D | **0.5 단위**. 1 M/D = 한 사람이 하루 종일 일한 양 | `2.5` |
| 메모 | 선택 | `현장 답사` |
| 기록일시 | **자동** (비워 두기) | |

규칙(두 방법 공통)
- 한 사람의 한 주 합계는 **5.0 이하** (휴가 포함). 대시보드는 넘으면 경고를 보여주고, 시트는 한 칸에 5 를 넘게 넣으면 셀에 경고가 표시됩니다.
- 기록이 없는 팀원은 대시보드 **E. 이번 주 → 주간 기록 미제출** 에 이름이 뜹니다.
- 대시보드 **C. 공수 관리 → 주간 기록 현황** 에서 최근 8주 누가 적었는지 한눈에 보입니다.

### 6.2 프로젝트가 새로 생겼을 때 — 등록 · 수정 · 삭제

**등록 (권장) — 대시보드 A. 포트폴리오 → 새 프로젝트**

1. **A. 포트폴리오** 탭 → 카드 위 도구 줄의 **새 프로젝트** 클릭. 입력 폼이 열립니다.
2. 필수: **행사명 · 유형 · 상태 · 행사 시작일 · 행사 종료일**. 담당PM(담당 책임자) · 발주처 · 계약금액(부가세 별도) · 게런티 · 예상 참가 · 베뉴 · 비고도 여기서 적습니다. 1일 행사는 시작일과 종료일을 같게. 게런티가 없는 유형(②·③)은 게런티 칸을 비웁니다. **프로젝트ID 와 등록일은 잠겨 있고 자동**으로 채워집니다.
3. **표준 마일스톤 함께 생성** 체크는 켜 둡니다(기본).
4. **저장** 클릭.
5. 정상: 상태 열에 새 카드가 나타나고 프로젝트ID(`P-2026-004` 형식)가 붙습니다. 시트에는 `프로젝트` 탭 행 1개, `정산` 탭에 같은 ID 의 빈 행 1개(자동 계산 열 포함), `마일스톤` 탭에 표준 마일스톤(일반 9건, 주최형 ③ 은 발주처 항목 2건을 뺀 7건)이 들어갑니다.
   - 빨간 오류가 폼 안에 뜨면 그 칸을 고치고 다시 저장합니다. 예: `행사 종료일은 시작일보다 앞설 수 없습니다.` · `담당PM "○○" 이(가) 팀원 탭에 없습니다.`(팀원을 먼저 §6.8 로 등록) · `계약금액(원) 은(는) 정수여야 합니다.`

**수정** — 카드 클릭 → 오른쪽 상세 → **프로젝트 수정** → 칸 고치기 → **저장**. 프로젝트ID 는 바꿀 수 없습니다. **상태 변경**(견적 → 계약 → 준비 → 진행 → 완료 → 정산완료, 또는 드롭)도 여기서 합니다.

**삭제** — 카드 클릭 → 상세 → **프로젝트 삭제** → 버튼 자리에 "정말 처리할까요?" 와 **함께 지워지는 배정·마일스톤·정산 건수** 가 보입니다 → **[확인]**.
- 삭제할 수 없는 경우: 그 프로젝트에 **공수기록이 1건이라도 있거나 `정산` 탭에 매출이 입력된 경우**. `공수기록 N건이 이 프로젝트를 참조해 삭제할 수 없습니다. 상태를 "드롭" 으로 바꾸세요.` 같은 안내가 뜹니다. 투입·정산 실적이 있는 프로젝트는 지우지 않고 **프로젝트 수정 → 상태 = 드롭** 으로 정리하는 것이 규칙입니다(드롭은 가동률·성과 집계에서 빠집니다).
- 지운 행은 시트 `변경이력` 탭 **이전 행(백업)** 열에 남습니다. 되돌리는 법은 §6.9.

**대안 — 시트 `프로젝트` 탭에 직접 입력** (여러 건을 한꺼번에 붙여 넣을 때)

1. `프로젝트` 탭 맨 아래 빈 행의 **행사명** 칸에 이름을 입력합니다.
2. 정상: **프로젝트ID**(`P-2026-004` 형식)와 **등록일** 이 자동으로 채워집니다. 안 채워지면 메뉴 **팀 보드 → 프로젝트 ID 채우기**.
3. 나머지 열을 채웁니다. 필수: **유형 · 상태 · 담당PM(담당 책임자) · 행사 시작일 · 행사 종료일**. 1일 행사는 시작일과 종료일을 같게. 게런티가 없는 유형(②·③)은 게런티 칸을 비웁니다.
4. 그 행의 아무 칸을 클릭한 상태에서 메뉴 **팀 보드 → 선택 프로젝트 표준 마일스톤 생성**.
5. 정상: **"표준 마일스톤 생성"** 창에 "대상 프로젝트 1개 / 새로 만든 마일스톤 9개 · 이미 있어 건너뜀 0개" 가 뜨고, `마일스톤` 탭에 그 프로젝트의 마일스톤이 추가됩니다(일반 9건, 주최형 ③ 은 발주처 항목 2건을 빼고 7건). 예정일은 행사 시작일·종료일에서 자동 계산됩니다. 여러 행을 선택하면 한 번에 여러 프로젝트를 처리합니다.
   - 같은 작업을 대시보드 **A. 포트폴리오** 에서 카드 클릭 → 오른쪽 상세 → **표준 마일스톤 생성** 버튼으로도 할 수 있습니다. 버튼을 누르면 "정말 처리할까요?" 확인이 한 번 더 나옵니다. **[확인]** 을 눌러야 기록됩니다.

### 6.3 담당자 배정 — 대시보드 **B. 배정 보드**

1. 대시보드 **B. 배정 보드** → 아래 **배정 편집** 카드 → **프로젝트** 드롭다운에서 프로젝트 선택.
2. **팀원 빠른 배정** 줄에서 팀원 이름 칩을 누르면 그 팀원 행이 표에 추가됩니다(역할은 주역할, 기간은 착수(예정)일~행사 종료일로 미리 채워짐). **계획 공수**(0.5 단위)만 적으면 됩니다. 역할·기간은 표에서 바꿀 수 있고, 같은 사람이 두 역할이면 **행 추가**로 행을 하나 더 만듭니다. 이미 행이 있는 팀원은 ✓ 로 표시됩니다.
3. **저장** 클릭.
4. 정상: 오른쪽 아래에 "배정 N행을 저장했습니다." 알림. 시트 `배정` 탭에 그 프로젝트 행이 새로 들어가고 **배정ID**(`A-0001` 형식)가 붙습니다. 위 **가동률 히트맵** 색이 바로 바뀝니다.
5. 저장은 **그 프로젝트의 행을 통째로 교체**합니다. 다른 프로젝트 행은 건드리지 않습니다. 배정을 빼려면 행의 **삭제** 를 누른 뒤 다시 **저장**.
6. 표에 회색 바탕에 **자동** 배지가 붙은 행이 있으면 업무 블럭(§6.11)에서 자동으로 만들어진 배정입니다. 이 행은 여기서 고칠 수 없고, 담당·공수를 바꾸려면 **A** 상세의 업무 블럭에서 고칩니다 — §6.13. 수동 행 옆에 "세부 합계 n M/D · 수동 m M/D" 배지가 붙어 있으면 같은 사람·파트의 업무 블럭 합계와 수동 값이 다르다는 뜻입니다.

> `배정` 탭에는 열을 추가하지 마세요 — 저장 시 행이 다시 쓰이며 추가 열 값이 어긋납니다. 비고 칸의 `자동(세부항목)` 문구도 손으로 넣거나 지우지 마세요(§6.13).

### 6.4 마일스톤 — 완료 처리 · 추가 · 수정 · 삭제

**완료 처리 — 대시보드 E. 이번 주**

1. **E. 이번 주 → 2주 내 마일스톤** 또는 **지연 마일스톤** 에서 항목 오른쪽 **완료 처리** 클릭.
2. 버튼을 누르면 "정말 처리할까요?" 확인이 한 번 더 나옵니다. **[확인]** 을 눌러야 기록됩니다(잘못 눌렀으면 **[취소]**).
3. 정상: "○○ 을(를) 완료 처리했습니다." 알림. 시트 `마일스톤` 탭 **완료일** 에 오늘 날짜가 들어가고 상태가 "완료" 로 바뀝니다.
4. 시트에서 직접 `마일스톤` 탭 **완료일** 칸에 날짜를 적어도 같은 효과입니다.

**추가 · 수정 · 삭제 — 대시보드 A. 포트폴리오 → 카드 클릭 → 상세 패널의 마일스톤 표**

1. 추가: 표 아래 **마일스톤 추가** → 마일스톤 이름 · 예정일(필수) · 담당(선택) → **저장**. 같은 프로젝트 안에 같은 이름은 만들 수 없습니다(`프로젝트 P-… 에 같은 이름의 마일스톤이 이미 있습니다`).
2. 수정: 행 오른쪽 **수정** → 이름 · 예정일 · 완료일 · 담당 고치기 → **저장**. 완료일을 비우면 다시 "예정" 또는 "지연" 으로 돌아갑니다. 완료 처리도 여기서 완료일을 적어서 할 수 있습니다. 마일스톤 **이름을 바꾸면** 그 아래 업무 블럭·주석의 마일스톤 칸도 함께 바뀝니다(알림에 "세부 항목 n · 주석 n 이름 갱신").
3. 삭제: 행 오른쪽 **삭제** → "정말 처리할까요?" → **[확인]**. 그 마일스톤 아래에 **업무 블럭(세부 항목)이 하나라도 있으면 지울 수 없습니다** — `세부 항목 N건이 있어 삭제할 수 없습니다. 항목을 먼저 지우세요.` 가 뜨니 §6.11 로 블럭을 먼저 지우세요. 마일스톤 전체에 달린 주석은 함께 지워집니다(변경이력에 백업).
4. 정상: 시트 `마일스톤` 탭에 그대로 반영되고 상태 열(F)은 수식이 다시 계산합니다. 표준 마일스톤 9종을 한 번에 만드는 것은 §6.2 의 **표준 마일스톤 생성** 버튼입니다.
5. 마일스톤 이름(행)을 클릭하면 **펼쳐져서** 그 아래 업무 블럭 표가 나옵니다 — §6.11.

### 6.5 행사가 끝난 뒤 — 정산 입력

프로젝트당 **1행** 입니다. 프로젝트를 대시보드에서 등록했으면 `정산` 탭에 그 ID 의 빈 행이 이미 있습니다.

**방법 1 (권장) — 대시보드 A. 포트폴리오 → 카드 클릭 → 상세 → 정산 입력**

1. 상세 패널의 정산 요약 옆 **정산 입력** 클릭.
2. 매출(원) · 직접비 집행(원) · 사전 등록(명) · 현장 참석(명) · 정산 상태를 적고 **저장**. 숫자는 정수(원·명)이고 비워도 됩니다. 매출 칸에 금액을 적으면 그 프로젝트는 대시보드에서 **실적** 으로 잡힙니다.
3. 정상: 상세의 정산 요약과 **D. 투입 대비 성과** 표가 바로 바뀝니다. 시트 `정산` 탭 B·C·F·G·J열에 값이 들어가고 D·E·H·I(자동 계산)는 그대로 살아 있습니다.
4. 정산 행은 지우지 않습니다. 잘못 넣었으면 값을 비워서 다시 저장하세요.

**방법 2 — 시트 `정산` 탭에 직접 입력**

| 열 | 입력 |
|---|---|
| 프로젝트ID | 드롭다운 |
| 매출(원) | 부가세 별도 금액. 비우면 `프로젝트` 탭 계약금액을 씁니다. 이 칸에 금액을 적으면 그 프로젝트는 대시보드에서 **실적**으로 잡힙니다(상태가 완료·정산완료여도 실적) |
| 직접비 집행(원) | 협력사·장소·제작 등 외부 지출 합계 |
| 사전 등록(명) | 사전 등록 확정 인원 |
| 현장 참석(명) | 현장 체크인 인원 |
| 정산 상태 | 미착수 / 진행 / 완료 |

실마진 · 실마진율 · 쇼업률 · 게런티 달성률은 **자동** 입니다. 대시보드 **D. 투입 대비 성과** 에 반영됩니다.

### 6.6 넣지 말아야 할 것

단가 · 급여 · 인건비 금액 · 개인 연락처는 어느 탭에도 넣지 않습니다(결정 D3). 이 보드는 사람의 시간(M/D)과 프로젝트의 성과만 다룹니다.

### 6.8 팀원 관리 — 대시보드 **B. 배정 보드**

1. **B. 배정 보드** → 가동률 히트맵 아래 **팀원 관리** 카드. 표에 이름 · 주역할 · 월 가용 M/D · 상태 · 색상이 나옵니다.
2. 추가: **팀원 추가** → 이름(필수) · 주역할(필수, 드롭다운) · 월 가용 M/D(비우면 20) · 상태(비우면 재직) · 색상(`#RRGGBB` 형식, 비우면 화면이 자동 배색) → **저장**. 같은 이름은 두 번 만들 수 없습니다(`같은 이름의 팀원이 이미 있습니다: ○○`).
3. 수정: 행의 **수정** → 주역할 · 가용 · 상태 · 색상 고치기 → **저장**. **이름 칸은 잠겨 있습니다** — 이름은 다른 탭(`프로젝트` 담당PM · `배정` · `공수기록` · `마일스톤` 담당)이 그대로 참조하기 때문입니다. 이름을 바꿔야 하면 시트 `팀원` 탭에서 고친 뒤 **편집 → 찾기 및 바꾸기(Ctrl+H)** 로 전체 탭에 함께 반영하고, 대시보드를 **새로고침** 하세요.
4. 삭제: 행의 **삭제** → "정말 처리할까요?" → **[확인]**. 담당PM · 배정 · 공수기록 · 마일스톤 담당 어디에든 이름이 남아 있으면 지울 수 없고 `○○ 을(를) 담당PM 1건 · 배정 2건 이(가) 참조해 삭제할 수 없습니다. 상태를 "퇴사" 로 바꾸세요.` 처럼 건수와 함께 안내가 뜹니다. 퇴사자는 지우지 말고 **수정 → 상태 = 퇴사** 가 규칙입니다(히트맵·경고에서 빠지고 과거 기록은 남습니다).
5. 팀 밖에서 도와주는 영업·지원 인력은 상태 **지원** 으로 — 배정은 되지만 가동률 히트맵·미기록 경고에는 나오지 않습니다.
6. 정상: 시트 `팀원` 탭에 그대로 반영되고, 새 팀원은 바로 **배정 편집** 의 팀원 칩과 담당PM 드롭다운에 나타납니다.

### 6.9 변경 이력 보기와 되돌리기

**보기**
- 대시보드 **E. 이번 주** 맨 아래 **최근 변경**: 최근 30건 — 일시 · 사용자(이메일) · 탭 · 키(프로젝트ID, 팀원 이름, "프로젝트ID · 마일스톤" 등) · 동작(추가 / 수정 / 삭제 / 저장) · 변경 내용(`계약금액(원): 50000000 → 60000000` 같은 줄).
- 시트 `변경이력` 탭: 전체 기록. 맨 오른쪽 **이전 행(백업)** 열에 지우거나 고치기 전 행이 `{"name":"답사","due":"2026-09-28", …}` 같은 글자 묶음(JSON 형식)으로 들어 있습니다. **이 탭은 스크립트만 씁니다** — 손으로 고치거나 지우지 마세요. 시트에서 직접 고친 것은 여기에 남지 않습니다(그건 시트 메뉴 **파일 → 버전 기록** 으로 봅니다).

**되돌리기 — 잘못 지운 행 복구 (예: 마일스톤 한 건)**
1. 시트 `변경이력` 탭 → **동작** 열이 "삭제" 인 행 중 **키** 열로 지운 것을 찾습니다.
2. 그 행의 **이전 행(백업)** 칸을 클릭 → 위쪽 수식 입력줄의 글자를 전부 선택(`Ctrl+A`) → 복사(`Ctrl+C`) → 메모장에 붙여 읽습니다. `"필드 이름": 값` 쌍이 보입니다(예 `"projectId":"P-2026-003"`, `"name":"답사"`, `"due":"2026-09-28"`, `"owner":"김OO"`).
3. 원래 탭(예 `마일스톤`) 맨 아래 빈 행에 값을 **열 순서대로** 다시 적습니다(프로젝트ID · 마일스톤 · 예정일 · 완료일 · 담당). 날짜는 `2026-09-28` 형식. 상태 열(F)은 수식이 채우니 비워 둡니다.
4. 프로젝트를 통째로 지운 경우(연쇄 삭제) 백업에는 프로젝트 행과 함께 지워진 배정 · 마일스톤 · 정산 행이 모두 들어 있습니다. `프로젝트` → `정산` → `마일스톤` → `배정` 순서로 넣습니다. 프로젝트ID 는 백업에 있는 값을 그대로 쓰고, `정산` 탭은 A·B·C·F·G·J열만 적습니다(D·E·H·I 는 수식 — 위 행을 아래로 채우기).
5. 대시보드 **새로고침**(머리말 버튼 또는 F5) → 복구된 행이 보이면 정상.

수정을 되돌릴 때는 **변경 내용** 열의 "이전 → 새" 를 보고 대시보드에서 다시 수정하면 됩니다(그 수정도 이력에 남습니다).

### 6.10 "다른 사용자가 먼저 수정했습니다" 가 뜰 때

저장을 눌렀는데 빨간 알림 **`다른 사용자가 먼저 수정했습니다. 화면을 새로고침한 뒤 다시 시도하세요.`** 가 나오면, 내가 폼을 연 뒤에 누군가(대시보드에서든 시트에서든) 같은 행을 바꾼 것입니다. 시트에는 그 사람의 값이 그대로 있고 **내 저장은 반영되지 않았습니다** — 아무것도 망가지지 않았으니 다음 순서로 하면 됩니다.

1. 머리말의 **새로고침** 버튼(또는 F5) → 최신 값이 보입니다(필터·탭은 유지).
2. 바뀐 내용을 확인하고 필요하면 다시 수정 → **저장**.
3. `다른 사용자가 저장 중입니다. 잠시 후 다시 시도하세요.` 는 다른 문구입니다 — 두 사람이 같은 순간에 저장 버튼을 누른 것이니 10초 뒤 다시 저장하면 됩니다.

### 6.11 업무 블럭 넣기 — 마일스톤 아래 "누가 무엇을 얼마나"

마일스톤마다 파트별로 해야 할 일을 **업무 블럭**(세부 항목)으로 넣고, 담당과 계획 공수(M/D)를 정합니다. 여기서 정한 공수 합계가 그 프로젝트의 **계획 공수**가 되고 배정에도 자동으로 반영됩니다(§6.13). 태스크 단위 일정표(커뮤니케이터의 WBS)를 대신하는 것이 아니라, "이 마일스톤에 어느 파트가 몇 M/D 들어가는가" 까지만 적습니다 — 파트별 역할 분담(R&R)을 이 단위로 적는 것입니다.

**넣기**

1. **A. 포트폴리오** → 카드 클릭 → 오른쪽 상세 → 마일스톤 표에서 마일스톤 이름(행)을 클릭해 **펼칩니다**. 그 마일스톤의 업무 블럭 표가 나옵니다(처음엔 비어 있음).
2. 표 아래 **블럭 추가** → **파트**(영업 · 모객 · 운영 PM · 현장 운영 · 디자인·제작 · 정산·리포트) 선택 → 그 파트의 블럭이 **체크 칩**으로 나옵니다(칩에 기본 M/D 표시. 이미 넣은 블럭은 ✓ 표시로 잠김. 주최형 ③ 프로젝트에는 영업 블럭이 나오지 않음).
3. 넣을 블럭을 여러 개 체크 → **추가**.
4. 정상: 표에 행이 생기고(파트 칩 · 블럭 · 담당 비어 있음 · 임팩트 · 난이도 · 계획 M/D = 기본값 · 예정일 = 마일스톤 예정일 · 상태 예정), 각 행에 **주석 1 · 미해결 1** 배지가 붙습니다 — 카탈로그의 "판단에 필요한 내용" 이 첫 주석(유형 요청)으로 자동 생성된 것입니다(§6.12). 시트 `세부항목` 탭에 행이, `주석` 탭에 첫 주석이 들어갑니다. 상세 패널 위 **계획 공수 합계** 카드의 M/D·M/M 이 바뀝니다.
   - 카탈로그에 없는 일이면 행의 **수정** 으로 블럭 이름을 직접 적어도 되고, 자주 쓰는 것이면 시트 `업무블럭` 탭에 추가해 두세요(대시보드는 새로고침 후 반영). `업무블럭` 탭이 아직 없으면 [블럭 추가] 안에 "기본 카탈로그 사용 중 — 시트 메뉴 [팀 보드 → 드롭다운 목록 새로고침] 이 `업무블럭` 탭을 만듭니다" 안내가 보입니다(오류 아님, §3.2).

**담당 · 공수 정하기**

5. 행의 **수정** → **담당** 을 고릅니다. 목록은 그 파트가 주역할인 팀원 → 이 프로젝트에 이미 배정된 팀원 → 이번 달 계획 가동률이 낮은 순으로 정렬돼 있고, 이름 옆에 "가동률 62%" 가 보입니다(100% 를 넘는 사람은 회색 — 넣을 수는 있습니다). **계획 M/D**(0.5 단위) · 예정일(비우면 마일스톤 예정일) · 상태 · 임팩트 · 난이도를 맞추고 **저장**.
   - **임팩트**(행사 성과·고객 관계에 미치는 영향)와 **난이도**(전문성·조율 범위)는 상 / 중 / 하 표시일 뿐, 누가 맡을 수 있는지를 제한하지 않습니다. 담당을 고르는 사람이 참고하는 정보입니다. 임팩트 상 또는 난이도 상인데 담당이 비어 있으면 **E. 이번 주 → 핵심 항목 미배정** 에 오릅니다.
6. 정상: 저장 알림 뒤 **B. 배정 보드** 에 그 담당의 **자동 배정 행**이 생기거나 갱신됩니다(§6.13). 합계 카드는 **"계획 공수 합계 12.5 M/D (0.63 M/M) · 파트별 · 담당별 · 미배정"** 처럼 M/D 와 M/M(월 가용 20 M/D 기준 환산)을 나란히 보여줍니다. 저장 단위는 M/D 이고 M/M 은 읽기 편하라고 붙인 환산값입니다.
7. 삭제: 행의 **삭제** → "정말 처리할까요? 주석 N건도 함께 지워집니다" → **[확인]**. 그 블럭의 주석이 함께 지워지고(변경이력에 백업) 자동 배정 행이 다시 계산됩니다.

**파트 필터** — 상세 패널 위 파트 칩을 고르면 업무 블럭 표가 그 파트만 보이고, 그 파트에 온 미해결 질문·요청이 위로 올라옵니다. 선택은 이 브라우저에 기억되니 각자 자기 파트를 골라 두면 됩니다(다른 사람 화면에는 영향 없음).

### 6.12 주석 남기기 · 해결하기 — 파트별 판단 근거

업무 블럭마다(또는 마일스톤 전체에) 파트가 의견을 남기는 곳입니다. 비고 한 칸 대신 **주석 스레드**를 씁니다.

| 유형 | 언제 |
|---|---|
| **판단 근거** | 왜 이렇게 정했는지(예: "후보 2곳 견적 비교, 반입 시간 조건이 좋은 곳으로") |
| **요청** | 다른 파트·담당에게 해 달라는 것(블럭을 넣을 때 자동으로 생기는 첫 주석이 이 유형) |
| **질문** | 판단하려면 알아야 하는 것(예: "섭외비 예산 범위가 정해졌나요?") |
| **결정** | 확정된 사항(예: "키비주얼 B안으로 확정") |

1. 업무 블럭 행의 **주석 n** 배지(또는 마일스톤 행의 배지)를 클릭 → 그 아래 스레드가 펼쳐집니다(파트 칩 · 유형 · 작성자 이름 또는 이메일 앞부분 · 일시 · 내용 · **해결** 체크).
2. 아래 입력 줄에서 **유형**(기본 요청) · **작성자 이름**(팀원 목록, 선택 — 비우면 접속 계정 이메일만 남음) · **내용** → **남기기**.
3. 정상: 스레드 맨 아래에 붙고 배지가 "주석 n+1 · 미해결 n+1" 로 바뀝니다. 시트 `주석` 탭에 행이 들어가며 **작성자(이메일)·일시는 자동**입니다.
4. 질문·요청이 처리되면 **해결** 체크 → 미해결 수가 줄고 **E. 이번 주 → 미해결 질문·요청** 에서 빠집니다. 해결 체크는 누구나 할 수 있습니다.
5. 내용을 고치는 것은 **작성자 본인만**(접속 이메일이 같을 때 **수정** 버튼이 보임). 다른 사람 주석은 고칠 수 없고 `주석은 작성자 본인만 수정할 수 있습니다. 해결 표시만 바꿀 수 있습니다.` 가 뜹니다.
6. **삭제는 대시보드에 없습니다.** 잘못 남긴 주석은 해결로 닫거나, 시트 `주석` 탭에서 그 행을 지우세요(시트에서 지운 것은 변경이력에 남지 않습니다).

**E. 이번 주** 의 **미해결 질문·요청** 카드는 파트 필터가 걸려 있으면 그 파트에 온 것만, 최신 20건을 보여줍니다. 항목을 클릭하면 그 블럭의 스레드로 갑니다.

### 6.13 자동 배정과 수동 배정 — 두 가지가 어떻게 만나는가

업무 블럭에 **담당과 계획 M/D** 를 정하면, 같은 (담당 · 파트) 의 M/D 를 합쳐 **B. 배정 보드** 의 배정 행이 자동으로 만들어집니다. 사람이 배정 편집기에서 만든 행(**수동 배정**)과 구분하기 위해 자동 행은 비고 칸에 **`자동(세부항목)`** 이라고 적혀 있습니다.

| 상황 | 대시보드가 하는 일 |
|---|---|
| 담당이 있는 블럭을 저장·추가·삭제 | 그 프로젝트의 자동 행을 전부 다시 계산해서 씁니다(배정ID 는 같은 담당·파트면 유지). 기간 = 블럭 예정일(없으면 마일스톤 예정일)의 가장 이른 날 −14일 ~ 가장 늦은 날, 착수일~정산 예정일 안으로 맞춤. 날짜가 없으면 착수일~행사 종료일 |
| 담당이 비어 있는 블럭 | 배정에 넣지 않고 합계 카드의 **미배정** 과 파트별 합계에만 보입니다 |
| 같은 (담당 · 파트) 에 **수동 배정 행이 이미 있음** | **자동 행을 만들지 않습니다**(같은 사람 공수가 두 번 잡히지 않게). 대신 그 수동 행 옆에 **"세부 합계 4 M/D · 수동 5 M/D — 수동 행을 지우면 자동으로 바뀜"** 배지가 붙습니다. 수동 값을 유지할지, 수동 행을 지워 자동으로 넘길지는 팀장이 정합니다 |
| 수동 행을 배정 편집기에서 **삭제 → 저장** | 그 프로젝트의 블럭을 다음에 저장할 때(아무 블럭이나 한 번 저장하면) 자동 행이 생깁니다 |
| 배정 편집기에서 자동 행을 고치려 함 | 자동 행은 회색 바탕 + **자동** 배지로 **잠겨** 있습니다. 담당·M/D·기간을 바꾸려면 **A** 상세의 업무 블럭에서 고치세요 |
| 블럭을 전부 지움 | 그 (담당 · 파트) 자동 행도 사라집니다 |

- 자동 행도 보통 배정과 똑같이 **가동률 히트맵 · 팀 계획 가동률 · 소진율 · 과부하 경고** 에 들어갑니다. 계산 방식은 바뀌지 않았습니다.
- 자동 행이 바뀔 때마다 `변경이력` 에 `배정 / 저장 / 세부항목 동기화: n행` 한 줄이 남습니다(바뀐 것이 없으면 남지 않음).
- 시트 `배정` 탭에서 비고 `자동(세부항목)` 을 손으로 지우면 그 행은 수동 행이 되어 다음 동기화 때 "겹침" 으로 처리됩니다. 반대로 수동 행 비고에 그 문구를 적으면 자동 행으로 취급돼 덮어써집니다 — 비고 칸의 이 문구는 건드리지 마세요.

## 7. 문제 해결

대시보드 오류는 오른쪽 아래 알림(빨간색) 또는 화면 가운데 **"화면을 불러오지 못했습니다"** 박스에 나옵니다. 박스 안 회색 글씨가 원인 문구입니다. 아래 표에서 그 문구를 찾으세요.

### 7.1 설치·배포 단계

| 증상 | 원인 | 조치 |
|---|---|---|
| **실행** 을 눌러도 권한 창이 안 뜨고 아무 반응이 없다 | 브라우저가 팝업을 차단했거나, 여러 구글 계정이 함께 로그인돼 있다 | 주소 창 오른쪽 팝업 차단 아이콘 → **항상 허용**. 그래도 안 되면 시크릿 창에서 회사 계정 하나만 로그인해 다시 시도 |
| 권한 창에 "이 앱이 차단되었습니다" | 회사 워크스페이스가 확인되지 않은 앱을 막음 | 워크스페이스 관리자에게 "Apps Script 내부 앱 허용" 요청 |
| 편집기 오른쪽 위에 **배포** 버튼이 없다 / 유형 선택에 **웹 앱** 이 없다 | 워크스페이스 정책이 웹 앱 배포를 막고 있음 | 관리자에게 "Apps Script 웹 앱 배포 허용" 요청. 허용이 안 되면 **폴백**: 같은 시트에 "대시보드" 탭을 추가해 QUERY·SUMIFS·조건부 서식으로 핵심 표를 만드는 방식으로 전환(설계 문서 SPEC §6.3). 데이터 탭 7개와 입력 방식은 그대로이므로 지금까지 넣은 데이터는 버리지 않습니다 |
| 액세스 권한 목록에 **"[회사 이름] 내 모든 사용자"** 가 없고 "본인만 / 모든 사용자" 만 있다 | 회사 워크스페이스 계정이 아닌 개인 계정으로 만들었음 | 회사 계정으로 §1 부터 다시. 혼자 테스트만 할 때는 **본인만** 으로 배포해도 됩니다 |
| 웹 앱을 열면 "스크립트 함수 doGet 을 찾을 수 없음" | `Code.gs` 가 저장되지 않았거나 일부만 붙여졌음 | §2.2 다시 → `Ctrl+S` → §8 절차로 새 버전 배포 |
| 웹 앱을 열면 "index 파일을 찾을 수 없음" 비슷한 문구 | HTML 파일 이름이 `index` 가 아님 | 파일 이름 옆 ⋮ → **이름 바꾸기** → `index` |
| 정보줄에 **샘플 데이터** 라고 뜬다 (웹 앱인데) | `index` 에 미리보기 파일을 붙였음 | `apps-script/index.html` 로 다시 붙이기 → §8 |
| 시트에 **팀 보드** 메뉴가 없다 | 시트를 열 때만 메뉴가 만들어짐 / `Code.gs` 저장 안 됨 | 시트 새로고침(F5). 그래도 없으면 편집기에서 `Ctrl+S` 확인 |

### 7.2 대시보드 화면 오류 문구

| 화면에 보이는 문구 | 원인 | 조치 |
|---|---|---|
| `"○○" 탭이 없습니다. 시트 메뉴 [팀 보드 → 초기 설정 실행]을 먼저 실행하세요.` | 탭 이름을 바꿨거나 탭을 지웠음 | 탭 이름을 원래대로(프로젝트 · 배정 · 공수기록 · 팀원 · 마일스톤 · 정산 · 설정 · 변경이력 · 세부항목 · 주석 · 업무블럭). 지웠다면 **팀 보드 → 초기 설정 실행(빈 시트)** — 있는 탭은 건너뛰고 없는 탭만 만듭니다(`변경이력`·`세부항목`·`주석` 은 대시보드에서 처음 저장할 때도 자동 생성, `업무블럭` 은 없어도 기본 카탈로그로 동작) |
| 화면이 비어 있다 / 숫자가 전부 0 / 특정 프로젝트만 안 보인다 | ① `설정` 탭 목록과 입력값이 다름(예: 상태에 "진행중" 처럼 목록에 없는 값) ② 1행 헤더를 고쳤음 ③ 필터가 좁음 | ① 드롭다운으로 다시 선택 ② 헤더를 계약 문서(`docs/DATA-CONTRACT.md` §3)와 똑같이 복구 ③ 필터 오른쪽 **필터 초기화**. 원인을 모르면 §7.4 실행 로그 확인 |

### 7.4 실행 로그 보는 법

1. 시트 메뉴 **확장 프로그램 → Apps Script**.

## 8. 업데이트 — 파일이 새로 나왔을 때

주소는 그대로 두고 내용만 바꾸는 방법입니다. **"새 배포" 를 누르면 주소가 바뀌므로** 쓰지 않습니다.

1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 바뀐 파일을 교체합니다.
   - 대시보드 화면이 바뀐 경우: 왼쪽 `index.html` 클릭 → `Ctrl+A` → `Delete` → 새 `apps-script/index.html` 내용 붙이기.
   - 스크립트가 바뀐 경우: `Code.gs` 도 같은 방법으로 교체.
   - 둘 다 바뀌었으면 둘 다.
   - 권한 범위가 바뀐 경우(예: 4턴 대시보드 편집 — 변경 이력에 사용자 이메일을 넣기 위한 권한 추가): `appsscript.json` 도 같은 방법으로 교체. 파일 목록에 안 보이면 왼쪽 **프로젝트 설정(톱니)** → **"appsscript.json" 매니페스트 파일을 편집기에 표시** 를 켭니다. 교체 뒤 첫 진입 때 권한 화면이 한 번 더 나옵니다(§4.2).
3. `Ctrl+S` 저장. 주황색 점이 사라지는지 확인.
4. 오른쪽 위 **배포 → 배포 관리**.
5. 현재 배포(§4.1 에서 만든 것) 오른쪽 **편집**(연필 아이콘).
6. **버전** 드롭다운 → **새 버전**. 설명에 `2차 · 화면 수정` 처럼 메모.
7. **배포**.

| **E. 이번 주** | 2주 내 마일스톤 · 지연 · 주간 기록 미제출 · 미배정 · 과부하 · 계획 공수 초과 · **핵심 항목 미배정** · **미해결 질문·요청** · **최근 변경** | **완료 처리**(확인 한 번 더) · 각 항목에서 해당 화면으로 이동 |

머리말(모든 탭 공통)의 **새로고침** 버튼은 시트를 다시 읽어 옵니다(필터·탭 유지). 시트에서 직접 고친 뒤, 또는 "다른 사용자가 먼저 수정했습니다" 가 떴을 때 누릅니다. 오른쪽 위 정보줄에는 지금 로그인한 사용자(이메일)가 보이고, 이 값이 `변경이력` 의 사용자 열에 기록됩니다.

**D. 투입 대비 성과** 의 매출은 **실적**(완료·정산완료이거나 `정산` 탭 매출이 입력된 프로젝트)과 **예정**(계약~진행 단계 프로젝트의 계약금액)으로 구분해 보여줍니다. 산점도는 **정산이 끝난 프로젝트만** 표시하고, 빠진 프로젝트는 차트 아래에 건수로 안내합니다. 정산 전 프로젝트는 성과표에서 계약금액만 보이고 정산 매출·실마진·공수당 매출 칸이 "—" 로 남습니다.

### 9.3 용어

| 용어 | 뜻 | 화면 표기 |
|---|---|---|
| **M/D** | 1인 1일 공수. 한 사람이 하루 종일 일한 양 = 1. 반나절 = 0.5 | "M/D(1인 1일 공수)", "계획 공수", "실투입 공수" |
| **계획 가동률** | 그 달에 배정된 계획 M/D ÷ 월 가용 M/D(기본 20). 배정 기간이 여러 달에 걸치면 날짜 수에 비례해 나눔 | 히트맵 색, 핵심 지표 "팀 계획 가동률" |
| **실가동률** | 그 달 주차에 실제 기록한 M/D ÷ 월 가용 M/D. 휴가(G-휴가)는 제외, 내부·영업은 포함 | C. 팀원별 이달 투입 구성 |
| **소진율** | 프로젝트에 실제 들어간 M/D ÷ 계획 M/D. 100% 를 넘으면 경고 | C. 프로젝트별 계획 대 실투입, E. 계획 공수 초과 |
| **실마진(직접비 차감)** | 매출 − 직접비 집행(협력사·장소·제작 등 외부 지출만). 사람의 시간은 금액으로 환산하지 않으므로 차감에 들어가지 않습니다 | D. 프로젝트 성과표 열 머리글 "실마진(직접비 차감)" |
| **실마진율** | 실마진 ÷ 매출. 기준선 외부 노출 25% · 목표 35% | D. 마진 기준선 |
| **쇼업률** | 현장 참석 ÷ 사전 등록 | "사전 등록 대비 참석" |
| **게런티 달성률** | 현장 참석 ÷ 게런티(최소 보장 인원). 게런티가 없으면 표시 안 함 | "최소 보장 인원 달성" |
| **G-내부 / G-영업 / G-휴가** | 프로젝트가 아닌 시간을 적는 공통 코드. 회의·관리 / 미성사 제안 / 휴가 | 공수기록 프로젝트ID 드롭다운 |
| **업무 블럭 / 세부 항목** | 마일스톤 아래 파트가 맡는 일 한 덩어리(예: "베뉴 서칭·계약"). 담당·임팩트·난이도·계획 M/D 를 가짐 | A 상세 마일스톤 펼침 표, "블럭 추가" |
| **계획 공수** | 프로젝트의 업무 블럭 계획 M/D 합계. 파트별·담당별·미배정으로 나뉨 | A 상세 "계획 공수 합계 n M/D (n M/M)" |
| **M/M** | 1인 1개월 공수. 계획 공수 M/D ÷ 월 가용 M/D(기본 20). 화면 환산값이고 저장은 M/D | 계획 공수 합계 카드 |
| **임팩트 / 난이도** | 행사 성과·고객 관계에 미치는 영향 / 전문성·조율 범위. 상·중·하 표시만 — 담당을 고르는 사람이 참고 | 업무 블럭 표 칩 |
| **핵심 항목** | 임팩트 상 또는 난이도 상인 업무 블럭. 담당이 비면 E 화면 경고 | E. 핵심 항목 미배정 |
| **주석** | 업무 블럭(또는 마일스톤)에 파트가 남기는 판단 근거 · 요청 · 질문 · 결정. 해결 체크로 닫음 | "주석 n · 미해결 n" 배지, 스레드 |
| **자동 배정 / 수동 배정** | 업무 블럭 합계로 만들어진 배정 행(비고 `자동(세부항목)`) / 배정 편집기에서 사람이 만든 행. 같은 담당·파트에 둘 다 있으면 자동은 생략 | B 배정 편집 표 "자동" 배지, "세부 합계 · 수동" 배지 |
| **업무 블럭 카탈로그** | 파트별 블럭 목록(기본 M/D·임팩트·난이도·판단에 필요한 내용). 시트 `업무블럭` 탭, 없으면 코드 기본값 33개 | "블럭 추가" 체크 칩 |
| **기준일** | 대시보드가 "오늘" 로 삼는 날짜. 시트 연결이면 실제 오늘, 미리보기는 2026-09-10 고정 | 정보줄 |

### 9.4 입력 규칙 요약

| 탭 | 누가 / 어디서 | 언제 | 꼭 지킬 것 |
|---|---|---|---|
| `프로젝트` | 담당 책임자 · **대시보드 A 새 프로젝트 / 프로젝트 수정·삭제**(§6.2). 여러 건 붙여 넣기는 시트 직접 입력 | 성사 즉시 | 필수 = 행사명·유형·상태·행사 시작일·종료일 · 유형·상태·담당PM 은 목록 값만 · 계약금액은 부가세 별도 · 프로젝트ID 는 자동, 바꾸지 않음 · 실적 있는 건은 삭제 대신 상태 "드롭" |
| `배정` | 팀장 · **대시보드 B 배정 편집**(§6.3) | 배정 변경 시 | 시트 직접 입력도 가능하지만 ID 가 비어 관리가 어려움 · 열 추가 금지 |
| `공수기록` | 팀원 전원 · **대시보드 C 공수 입력**(§6.1). 시트 직접 입력은 대안 | 매주 월요일 오전 | 주차 = 지난주 월요일 · 0.5 단위 · 주 합계 5 이하(넘으면 경고) · 같은 코드는 한 주에 한 줄 · 기록일시는 자동 |
| `팀원` | 팀장 · **대시보드 B 팀원 관리**(§6.8). **이름 변경만 시트에서** | 입·퇴사 시 | 이름은 다른 탭이 참조 — 바꿀 때 시트에서 찾기·바꾸기(Ctrl+H)로 전체 반영 · 퇴사자는 삭제 대신 상태 "퇴사" · 외부 지원 인력은 상태 "지원" |
| `마일스톤` | 자동 + 담당 · **대시보드 A 상세(추가·수정·삭제) · E 완료 처리**(§6.4) | 생성 시·완료 시 | 표준 마일스톤은 새 프로젝트 옵션/버튼/메뉴로 생성 · 같은 프로젝트에 같은 이름 없음 · 상태 열(F)·행사명 열(G, 1행 수식)은 수식이라 건드리지 않음. G열이 안 보이면 메뉴 **팀 보드 → 드롭다운 목록 새로고침** 한 번 |
| `정산` | 정산 담당 · **대시보드 A 상세 정산 입력**(§6.5) | 행사 종료 후 | 프로젝트당 1행(대시보드 등록 시 자동 생성) · 행을 지우지 않고 값만 비움 · D·E·H·I열은 수식이라 건드리지 않음 |
| `설정` | 관리자 1명 · **시트에서만** | 거의 없음 | 목록 문구를 바꾸면 기존 데이터와 어긋남. 바꿔야 하면 데이터 탭도 함께 찾기·바꾸기 · 대시보드에는 설정 편집 화면이 없음 |
| `변경이력` | **스크립트만 씀** · 사람은 읽기만 | 대시보드에서 저장·삭제할 때마다 자동 | 손으로 고치거나 지우지 않음 · 헤더 7개 유지 · 되돌리기는 §6.9 · 시트에서 직접 고친 것은 기록되지 않음(파일 → 버전 기록) |
| `세부항목` | 각 파트 담당 · **대시보드 A 상세 마일스톤 펼침(블럭 추가 · 수정 · 삭제)**(§6.11) | 마일스톤 계획 시 | 세부ID 자동 · 같은 마일스톤에 같은 블럭 이름 없음 · 계획 M/D 0.5 단위 · 담당을 넣어야 배정에 반영 · M열(행사명)은 수식 · 시트 직접 입력은 ID 가 비어 권장하지 않음 |
| `주석` | 각 파트 · **대시보드 A 상세 스레드**(§6.12) | 판단·요청·질문·결정이 생길 때 | 작성자·일시는 자동 · 내용 수정은 본인만 · 해결 체크는 누구나 · 삭제는 시트에서만 |

공통
- 1행(헤더)은 절대 수정하지 않습니다.
- 각 탭 **A열**(프로젝트ID · 주차 · 이름 · 세부ID · 주석ID · 파트)이 비어 있는 행은 대시보드가 무시합니다.
- 탭 이름 11개는 바꾸지 않습니다.
- 대시보드에서 저장할 때 "다른 사용자가 먼저 수정했습니다" 가 뜨면 §6.10 — 새로고침 후 다시.
- 드롭다운이 있는 칸은 드롭다운으로만 선택합니다(띄어쓰기 하나만 달라도 화면에서 빠집니다).
- 날짜는 셀 서식이 날짜여야 합니다. 직접 입력할 때는 `2026-09-07` 형식.
- 넣지 말아야 할 것은 §6.6 을 따릅니다.
